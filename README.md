# 杨一飞 · 机器人操作项目选集

无构建依赖的 GitHub Pages 静态站。首页、两篇文章及素材使用相对路径，支持项目站点的 `/robotics-portfolio/` 子路径。

- `index.html` 为项目选集首页。
- `robodojo-agent.html` 包含 42 项 RoboDojo 仿真任务的 Astra 成绩、失败归因和 Harness 版本对比。
- `dobot-sim2real.html` 记录 Isaac Sim 赛题开发、真机示教、π₀.₅ 微调与推理验证。

## 仿真素材

- `assets/robodojo/arrange-tool-loop` 取自 `agent-tools-02` 的数字排列成功轮，包含头部相机回放和终态封面。

## Dobot 赛题与真机素材

- `assets/dobot/competition-tasks.gif` 并排呈现[中国人工智能学会赛事公告](https://www.caai.cn/site/content/5476.html)中的三项赛题，网页使用同一内容的 MP4 循环播放版。
- `assets/dobot/insert-tube-3x.mp4` 和 `assets/dobot/pull-tube-plug-finetune-2x.mp4` 分别为 3 倍速插管和 2 倍速拔塞的真机视频，倍速标注嵌入画面。
